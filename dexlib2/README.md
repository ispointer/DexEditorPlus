# dexlib2

Vendored copy of `org.smali:dexlib2:2.5.2`.

The source in `src/main/java` is extracted from the published Maven Central sources jar so this project keeps a local `dexlib2` module at the repo root, similar to `filepicker`.

Runtime and compile support dependencies still come from Maven Central:

- `com.google.code.findbugs:jsr305:3.0.2`
- `com.google.guava:guava:27.1-android`

Upstream project: <https://github.com/JesusFreke/smali/tree/master/dexlib2>
